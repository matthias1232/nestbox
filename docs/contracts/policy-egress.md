# Policy and Egress Events
Policies are versioned, validated, diffed, assigned and reversible.
Egress events include time, sandbox, destination, decision, route, latency and correlation ID.
TLS decryption is disabled by default. Syslog export is structured, redacted and uses secure transport.
Proxy selection remains an architecture decision: explicit, transparent or hybrid must meet attribution, telemetry, privacy and performance criteria.
