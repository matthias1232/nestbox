# Code of Conduct

This project adopts the Contributor Covenant, version 2.1.

Be respectful, assume good intent, and critique the work rather than the person. Harassment,
discrimination and personal attacks are not tolerated.

Enforcement: report to conduct@mmbits.com. Reports are handled confidentially by the maintainer.

Full text: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
